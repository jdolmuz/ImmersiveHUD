Immersive HUD for **World of Warcraft: Forever**. Your HUD fades while you explore and comes back for combat, clicks, targets, casting, typing, mouseover and low health.

## Install
Unzip `ImmersiveHUD-v*.zip` into `World of Warcraft\_forever_\Interface\AddOns\` and `/reload`. Type `/ihud` for settings.

## Fadeable elements
Action bars, player/pet frames, target/focus frames, party/raid frames, buffs/debuffs, Cooldown Manager, micro menu & bag bar, XP/reputation bars, quest tracker, chat (including the input box), minimap.

## In this release
- First public release.
- Fixed a Lua error from the mouseover check (`MouseIsOver` doesn't exist in Forever).
- The chat input box now fades with chat.
- Built-in error catcher: `/ihud errors` and `/ihud frames`.
